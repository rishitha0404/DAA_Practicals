The recursive factorial function calculates n! by calling itself with n-1 until it reaches the base case.
For example, 5! = 5 × 4 × 3 × 2 × 1 = 120.
It takes O(n) time and O(n) stack space.

The iterative factorial function calculates the result using a loop instead of recursive function calls.
It avoids recursion overhead and requires only a single variable for calculation.
It takes O(n) time and O(1) extra space.
